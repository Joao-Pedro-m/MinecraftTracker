# 🗺️ Minecraft Tracker

Um **Tracker/Rastreador de Colecionáveis e Tarefas** desenvolvido de forma nativa em **React (Vite)** e estilizado com **Tailwind CSS**. Criado especificamente para jogadores em modo solo (*Singleplayer*) organizarem o seu progresso de exploração, gerirem a obtenção de itens raros e planearem as suas sessões de jogo.

---

## ✨ Funcionalidades Principais

*   🗂️ **Categorias Completas:** Acompanhamento detalhado de **Moldes de Ferraria** (Smithing Trims), **Discos de Música**, **Fragmentos de Cerâmica** (Pottery Sherds) e **Padrões de Estandarte** (Banner Patterns).
*   📖 **Guia de Villagers:** Agrupamento estratégico de encantamentos por funções de utilidade e combate (Anti-Warden, Kit Elytra, Ferramentas, Armas).
*   🗺️ **Guia de Drops (*Drop Info*):** Informação detalhada em modais interativos sobre as estruturas, coordenadas e probabilidades de obtenção de cada item.
*   🔍 **Filtros e Pesquisa Dinâmica:** Campo de busca em tempo real por nome e um interrutor (*Toggle*) para ocultar instantaneamente os itens já concluídos.
*   📌 **Lista de Objetivos da Sessão (*Pinned*):** Sistema de afixação rápida para marcares os objetivos prioritários da tua próxima sessão de exploração.
*   📊 **Progresso Modular:** Barras de progresso visuais independentes para cada categoria, acompanhadas de um indicador global de conclusão.
*   💾 **Segurança e Persistência:** Sincronização automática com o `localStorage` do navegador, complementada por botões dedicados de **Exportar/Importar Backup em JSON** para nunca perderes o teu progresso.

---

## 🛠️ Tecnologias Utilizadas

*   **React (Vite)** — Interface reativa de alta performance.
*   **Tailwind CSS** — Estilização moderna baseada em utilitários (*Dark Mode* nativo).
*   **Minecraft Wiki (wiki.gg)** — Suprimento de texturas e *sprites* pixelados otimizados.

---

## 🚀 Como Executar o Projeto Localmente

Certifica-te de que tens o Node.js instalado no teu sistema (ou a correr através do WSL no Windows).

1. Clona o repositório:
```bash
   git clone [https://github.com/Joao-Pedro-m/MinecraftTracker.git](https://github.com/Joao-Pedro-m/MinecraftTracker.git)

```

2. Entra na pasta do projeto:

```bash
cd MinecraftTracker

```


3. Instala as dependências:
   
```bash
npm install

```


4. Inicia o servidor de desenvolvimento:
   
```bash
npm run dev

```
